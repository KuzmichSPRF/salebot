📖 Краткая инструкция администратора

1. Управление комнатами (категориями)
• /newroom Название — создать
• /editroom Старое | Новое — переименовать
• /delroom Название — удалить

👑 Модераторы (только Главный админ):
• /assignadmin ID Название — назначить модератора на комнату
• /revokeadmin ID Название — снять права
• /adminlist — список всех админов

2. Публикация в группы/каналы
• Добавление: Напишите /addgroup внутри группы или /addgroup ID Название боту в ЛС.
• Настройка комнат: Напишите /setrooms внутри группы или используйте /groups в ЛС бота.
• Удаление: Команда /delgroup в группе или через /groups в ЛС.

3. Процесс модерации объявлений
При поступлении заявки админу приходят кнопки:
• ✅ Одобрить — моментальная публикация во все привязанные группы этой комнаты.
• ❌ Отклонить — бот попросит указать причину (пользователь получит уведомление).

4. Работа с базой
• Кнопка «🏠 Комнаты» — просмотр всех активных объявлений по категориям.
• Кнопка «🗑 Удалить» под объявлением — убирает лот из базы и автоматически удаляет сообщения из всех групп рассылки.

5. Для пользователей
• «📬 Мои объявления» — проверка статуса и возможность самостоятельного удаления (удаляется отовсюду).

💡 Полезные советы:
• Заявка должна содержать фото и текст одним сообщением.
• Пользователь не может создать новую заявку, пока старая на модерации.

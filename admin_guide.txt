📖 Руководство администратора бота объявлений

Этот бот предназначен для сбора объявлений от пользователей, их ручной модерации и последующей автоматической публикации в привязанные группы/каналы.

1. Управление комнатами (категориями)
Комнаты — это категории или папки, по которым сортируются объявления. Пользователь выбирает комнату при подаче объявления.

Для управления комнатами нажмите кнопку «🛠 Управление комнатами» в главном меню:
• Создать новую комнату: /newroom Название (Пример: /newroom Автомобили)
• Переименовать комнату: /editroom Старое_название | Новое_название (Все объявления перенесутся автоматически)
• Удалить комнату: /delroom Название (Осторожно, если там есть объявления)
 
👑 Управление правами (Для Главного администратора):
Главный администратор (заданный в .env файле) может назначать модераторов на конкретные комнаты. Эти модераторы будут получать уведомления только из своих комнат и смогут только одобрять/отклонять/удалять объявления в них.
• Назначить админа комнаты: /assignadmin ID Название (Например: /assignadmin 12345678 Автомобили)
• Удалить админа комнаты: /revokeadmin ID Название
• Посмотреть список всех админов: /adminlist

2. Настройка автоматической публикации (Группы и Каналы)
Когда вы одобряете объявление, бот автоматически пересылает его в привязанные Telegram-группы. 

Как добавить группу/канал для рассылки:
• Способ А (Для групп/чатов):
  1. Добавьте бота в нужную группу и назначьте его администратором.
  2. Прямо в этой группе напишите команду: /addgroup
• Способ Б (Для каналов или через личные сообщения):
  1. Добавьте бота в канал и дайте ему права на публикацию сообщений.
  2. Узнайте ID вашего канала (он начинается с -100, например -100123456789).
  3. Отправьте боту в личные сообщения команду: /addgroup ID Название
  
💡 Важно: После добавления группы или канала бот предложит выбрать комнаты, из которых в этот чат будут автоматически публиковаться объявления. Нажмите на нужные комнаты и затем «💾 Сохранить».

Управление привязанными чатами:
• Посмотреть список чатов: Отправьте боту /groups
• Настроить комнаты рассылки: Введите /groups и нажмите кнопку «⚙️ Настроить» рядом с нужным чатом, чтобы изменить список публикуемых категорий.
• Удалить чат из рассылки: Введите /groups и нажмите кнопку «❌ Удалить». Либо напишите /delgroup прямо внутри удаляемой группы.

3. Процесс модерации объявлений
Как только пользователь отправляет картинку с текстом и выбирает комнату, вы получаете уведомление.

Под сообщением будут две кнопки:
• ✅ Одобрить — объявление сохраняется в комнате, пользователь получает уведомление об успехе, а лот моментально рассылается по всем привязанным группам.
• ❌ Отклонить — бот предложит указать причину отказа. Вы можете написать её текстом, выбрать "Без причины" или отменить действие. Пользователь получит уведомление вместе с причиной.

4. Просмотр базы объявлений
• Нажмите «🏠 Комнаты» или введите команду /rooms для просмотра статистики.
• Нажмите на инлайн-кнопку с названием нужной комнаты, и бот пришлет все одобренные объявления из этой категории.
• Администраторы при просмотре объявлений видят кнопку «🗑 Удалить», которая убирает объявление из базы бота и автоматически удаляет его из всех привязанных групп.

5. Управление своими объявлениями (Для пользователей)
Пользователи могут отслеживать статусы своих заявок через меню «📬 Мои объявления».
• Активные объявления (находящиеся на модерации или уже одобренные) можно самостоятельно удалить нажатием на соответствующую кнопку.
• При удалении пользователем одобренного объявления, оно также автоматически стирается из всех привязанных групп рассылки.

💡 Полезные советы:
1. Обязательное фото: Бот принимает заявки только если пользователь прикрепил фото к тексту одним сообщением.
2. Защита от спама: Пока заявка пользователя на модерации (или он не выбрал комнату), он не может прислать новое объявление.
